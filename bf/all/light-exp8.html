How to read the result: a transaction change modifies its leaf hash and Merkle root. The block hash then changes, so the next block’s stored previous hash no longer matches. “Recalculate hashes” demonstrates why changing one block requires rebuilding later links; real networks rely on consensus, not just local recalculation.
