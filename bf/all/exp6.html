RLP Encoder / Decoder

Enter transaction fields as hex strings, encode them with Recursive Length Prefix (RLP), then decode the result to verify the original values.

01 Transaction fields

Use a JSON array of hex strings. Each string represents one byte sequence in the transaction list.

Ready. Select “Encode + Decode” to run the demo.

02 Encoded and decoded output

The encoded result is shown as hex for readability. The decoded values should match the input fields.

Note: This is a demonstration of RLP serialization, not a signed or broadcastable Ethereum transaction. The sample values are illustrative. Ethereum transaction formats differ by transaction type, and numeric fields must be represented as bytes according to the protocol.
Dependency. Uses the @ethereumjs/rlp library from a CDN — internet access is required to load it. Scope. Encoding and decoding run entirely in your browser.
