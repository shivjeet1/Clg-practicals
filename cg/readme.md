# CG- Computer Graphics 

## SDL BGI library must be installed before running code.

> [Find it here](https://sdl-bgi.sourceforge.io/)


### To compile a program

```bash
$ gcc <name>.c -lSDL_bgi -lm -o <name>.out
```

### To run a program

```bash
$ ./<name>.out
```

## Example

### To compile
```bash
gcc exp1.c -lSDL_bgi -lm -o exp1.out
```

### To run
```bash
./exp1.out
```
